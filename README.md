# 📊 Sales Data Analytics Dashboard
## 📌 Project Overview
This project presents an interactive Sales Data Analytics Dashboard designed to analyze and visualize sales performance across different regions, product categories, products, order IDs, and dates.
The dashboard helps transform sales data into meaningful business insights through charts, graphs, and interactive filters.
## 🎯 Project Objectives
- Analyze sales performance across different regions.
- Understand category-wise sales distribution.
- Compare product-wise sales performance.
- Track sales by order ID.
- Analyze date-wise sales trends.
- Identify key business insights using data visualization.
## 🛠️ Tools & Technologies
- Microsoft Excel
- Data Analysis
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization
## 📈 Dashboard Features
1. **Sales by Region** – Compares North and South region sales.
2. **Sales by Category** – Displays sales distribution across Electronics, Furniture, and Office.
3. **Sales by Order ID** – Shows individual order sales performance.
4. **Product-wise Sales** – Analyzes sales of Pen Set, Monitor, Headset, and Bookshelf.
5. **Month-wise Sales** – Displays sales performance across different dates.
6. **Interactive Slicers** – Filters dashboard data by Region, Date, and Order ID.
## 🔍 Key Insights
- South region generated higher sales than North region.
- Electronics is the highest-performing product category.
- Monitor generated the highest sales among the displayed products.
- Interactive slicers make it easier to analyze sales from different perspectives.
